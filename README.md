#  인공지능 컴퓨터 견적 챗봇

> 인공지능응용 수업 과제로 제작한 Discord 기반 컴퓨터 견적 추천 챗봇입니다.

##  프로젝트 개요

###  배경
컴퓨터 부품을 검색하거나 견적을 구성할 때, 사용자들은 여러 웹사이트를 돌아다니며 많은 시간과 노력을 소비하게 됩니다. 또한 가격 정보가 분산되어 있고, 부품 간의 호환성 문제로 인해 적절한 조합을 찾는 데 어려움이 존재합니다.

###  목표
이 챗봇은 사용자가 Discord 채팅을 통해 손쉽게 컴퓨터 부품 정보를 검색하고, 적절한 견적 구성을 추천받을 수 있도록 돕는 것을 목표로 합니다.  
인공지능을 통해 사용자의 요청을 이해하고, MySQL 데이터베이스와 연동하여 적절한 정보를 제공하며 효율적인 의사결정을 지원합니다.

###  정의
- 사용자 편의성을 높이고 정보 탐색 및 견적 추천 과정을 단순화
- 시간 절약과 효율성 제공
- 향후 기능 확장을 고려한 구조 설계

##  주요 기능

-  Discord 명령어 기반 챗봇 응답
-  원하는 컴퓨터 부품 정보 검색
-  실시간 컴퓨터 견적 구성 추천
-  MySQL 기반 데이터 저장 및 관리

---

##  프로젝트 예시

> 예시 명령어
>
> !견적 -> 임의로 만든 컴퓨터 견적 용도에따라 1번부터 6번까지 구성하였습니다. !번호 를 입력하면 해당견적을 자세하게 보여줍니다
> (부품이름) 가격알려줘 -> 예) 7800x3d 가격 알려줘 이런 형태로 질문을 하면 db에 저장된 부품의 가격정보를 알려주고 다나와 사이트의 링크를 알려줍니다.
> !검색 내용 -> gpt 모델의 경우 마지막 학습일자가 현재와 차이가 나기 떄문에 가지고 있는 정보가 최신이 아닐 수 있습니다, 따라서 google search api를 통해서 최신정보를 검색하여 보여줄 수 있도록 하였습니다.
